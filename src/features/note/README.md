# 노트 게시판

`/notes`(게시판)와 `/notes/:id`(노트 상세 · 다이어리)입니다. Figma 02-3의 SCR-NOTE-01 노트 게시판, 검색 결과 없음, SCR-NOTE-02 노트 상세 · 다이어리(A1 꿀우유 + A2 살구 크림 스티커)를 구현했습니다. 파트 배정 전·프로젝트 기간이 아닐 때도 열 수 있도록 홈 상태(useHomeMode)로 막지 않았습니다.

## 연결 방법 (아직 안 함)

라우트는 `routes.tsx`에만 정의했고 공통 파일은 건드리지 않았습니다. 화면을 열려면 아래 세 곳을 바꿔야 합니다.

1. `app/router.tsx`: `noteRoutes`를 import해서 children에 추가합니다.
2. `features/admin/routes.tsx`: `{ path: 'notes', element: <ComingSoonPage title="노트" /> }`를 지웁니다. 남아 있으면 경로가 겹쳐서 준비 중 화면이 먼저 열립니다.
3. `components/common/BottomNav.tsx`: 노트 탭에 `to: '/notes'`와 `activeIcon`을 넣습니다. 켜진 아이콘은 `@/assets/note/nav-notes-active.svg`입니다. 상세(`/notes/:id`)에서는 탭이 없습니다.

홈은 이미 연결되어 있습니다. 지난 기수 카드는 같은 id의 상세로, 더 보기는 `/notes?cohort=past`로, 프로젝트 기간이 아닐 때의 노트 둘러보기는 `/notes`로 이동합니다.

## 파일

- `types.ts`: Note/NoteFilters 데이터 계약. 파트는 가이드와 같은 코드(PM/DESIGN/FRONTEND/BACKEND)에 운영진(STAFF)을 더했습니다.
- `mock/data.ts`: 노트 13개(PM 9개), 필터 선택지, 검색 추천어. 홈 카드와 같은 id(`changed-topic`, `meeting-rules`, `presentation-deck`)를 씁니다. 우리 기수는 홈 노트 통계의 기수(14)를 따릅니다.
- `api.ts`: getNotes/getNoteById. 실제 API로 교체할 지점입니다. 검색·필터·정렬은 지금 화면에서 합니다. 서버로 옮기면 `filterNotes` 대신 쿼리 파라미터를 넘기세요.
- `noteFilters.ts`: URL 쿼리 ↔ 필터 변환, 검색·필터·정렬, 카드·상세 문구. 처음 들어오면 홈 사용자의 파트가 골라져 있습니다(배정 전이면 전체).
- `noteStore.ts`, `useNoteState.ts`: localStorage `likelion-note-state:v1`의 읽음·도움돼요·저장 id 목록. useSyncExternalStore로 같은 화면·다른 탭의 변경을 구독하고, 저장에 실패하면 메모리에 유지하며 토스트로 알립니다.
- `useNotes.ts`: 게시판과 상세가 같은 React Query 조회 결과를 씁니다.
- `note.css`: 노트 열기 전환.

## 게시판

- 필터(기수·파트·시점·상황)와 정렬은 URL 쿼리(`cohort`, `part`, `phase`, `tag`, `sort`, `q`)에 저장합니다. 기본값은 쿼리에서 지웁니다. 상세로 갔다 돌아와도, 새로고침해도 그대로입니다. `userPart` 같은 개발용 쿼리는 유지합니다.
- 칩 줄은 가로로 밀 수 있고 화면 오른쪽 끝까지 이어집니다. 상황 태그는 다시 누르면 해제됩니다.
- 필터 묶음은 스크롤하면 위에 붙습니다. 붙었을 때만 바탕과 그림자를 깔아서 평소에는 모눈이 그대로 보입니다.
- 검색은 제목·요약·본문·태그에서 띄어쓰기와 대소문자를 무시하고 찾습니다. `#`으로 시작하면 태그만 찾습니다(`#일정지연`으로 `#일정 지연`도 찾음). 한글 조합이 끊기지 않도록 입력값은 화면 상태가 기준이고 URL에 따라 씁니다.
- 검색 중에는 손글씨 머리말을 숨기고 오른쪽 위 일러스트가 돋보기 사자로 바뀝니다(Figma 검색 결과 없음 화면 기준).
- 결과가 없으면 검색 결과 없음 화면을 보여주고, 추천 칩을 누르면 그 말로 다시 찾습니다. 검색어 없이 필터만으로 비었을 때는 같은 틀에 '필터 모두 풀기'를 보여줍니다.
- 열어 본 노트는 카드가 흐려지고 제목 옆에 '읽음'이 붙습니다. 도움돼요를 누른 노트는 숫자가 1 올라갑니다.

## 노트 상세 · 다이어리

- 게시판의 필터를 쿼리로 이어받아 헤더의 'n / 전체'와 '다음 장'을 게시판에서 보던 순서로 보여줍니다. 홈처럼 다른 곳에서 열어 지금 필터에 없는 노트면 전체 노트 최신순을 기준으로 합니다. 마지막 노트에서는 다음 장을 숨깁니다.
- 뒤로 버튼은 같은 필터의 게시판으로 돌아갑니다. 책상 색은 상태바 자리까지 덮고, BottomNav는 없습니다.
- 책갈피는 저장 토글입니다(채움 = 저장). 저장 목록 화면은 아직 없어서 상태만 보관합니다. 켜진 모양은 Figma에 없어서 같은 경로의 안을 채운 아이콘으로 만들었습니다.
- 도움돼요는 토글이며, 켜지면 연한 주황 바탕이 됩니다(켜진 모양은 Figma에 없음).
- 종이 모눈과 스프링은 Figma 에셋을 세로로 반복해서 글이 길어도 끝까지 이어집니다. 스프링은 고리 간격이 이음매에서도 48px이 되도록 576px로 반복하고, 잘린 고리가 없게 맞춥니다.
- 다이어리 색(책상 #F5EBDA · 종이 #FFFDF7 · 글자 #5A3E2B · 보조 글자 #A08568)은 이 화면에서만 쓰여서 테마 토큰에 넣지 않았습니다. 스티커(#FCE3D8/#B0553F)와 형광펜(#FCEBD6)은 기존 rose·highlight 토큰과 같습니다.

## 노트 열기 전환

Figma '노트 열기 전환' 프로토타입(Smart Animate 320ms · ease-out)을 React Router의 `viewTransition`(View Transitions API)으로 구현했습니다. 카드를 누르면 그 카드만 `note-paper`라는 이름을 받아 상세의 종이로 커지고, 스프링(`note-spring`)은 왼쪽에서 밀려 들어옵니다. 상세의 뒤로 버튼은 반대로 종이가 카드로 접히고 스프링이 왼쪽으로 빠집니다. 다음 장으로 넘길 때는 종이끼리 바뀝니다.

- 지원하지 않는 브라우저(현재 Firefox 일부 버전 등)에서는 효과 없이 바로 이동합니다.
- 브라우저·기기의 뒤로 가기 제스처는 전환 없이 이동합니다.
- 동작 줄이기 설정을 켜면 애니메이션을 끕니다.
- 게시판으로 돌아오면 목록이 맨 위부터 보입니다. 열었던 카드가 화면 밖이면 종이가 화면 밖 카드 자리로 접힙니다. 스크롤 위치 복원은 추후 과제입니다.

## 에셋

새 에셋은 `src/assets/note/`에 있습니다(모눈 배경 2종, 손글씨 머리말, 검색·지우기·뒤로·다음·발자국 아이콘, 종이 모눈, 스프링, 켜진 노트 탭 아이콘). 사자·체크·전구 스프라이트와 손글씨 인용(`quote-presentation.svg`), 물음표 아이콘은 기존 홈 에셋과 공통 `QuestionIcon`을 그대로 씁니다. 손글씨 머리말은 GRIUN 폰트로 교체될 예정이라 이미지로 두고 alt에 문구를 넣었습니다.

검증: 390px 기준으로 게시판·검색 결과 없음·상세 화면을 Figma와 비교, 타입 검사·ESLint·Prettier 통과. 라우트가 연결되지 않아 앱 안에서의 탭 이동과 전환 애니메이션은 라우트 연결 후 실제 브라우저에서 확인이 필요합니다.
